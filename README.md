# Внутренняя страница «Новогодняя ночь длиной в страну»

Статичная страница-витрина для внутреннего портала ПСБ. Рассказывает сотрудникам о новогодней платформе (акция с 1 декабря по 17 января) и ведет на нее по QR-коду, кнопке и ссылке psbng2027.ru.

## Технологии

- HTML, CSS и JavaScript (ES5) без библиотек, без сборки и без бэкенда.
- Внешних запросов нет: шрифты, картинки и скрипты лежат в папке `assets`.
- Страница ничего не отправляет и не сохраняет. JavaScript нужен только для окон поверх страницы и демо квиза (баллы не считаются).

Чтобы посмотреть страницу, достаточно открыть `index.html` в браузере.


## Дизайн-система

Все цвета, шрифты, размеры текста, отступы, скругления и тени заданы переменными в начале `assets/css/base.css` (блок `:root`). Остальные файлы стилей берут значения только оттуда, поэтому поменять, например, акцентный цвет или скругление карточек можно в одном месте.

- Текст: шкала из восьми размеров — заголовок страницы, заголовок блока, малый декоративный заголовок, заголовок шага, вводный текст, основной текст, подписи, надписи капсом. На телефоне шкала уменьшается целиком.
- Начертания: 400 — текст, 500 — акцентный текст и варианты ответа, 700 — заголовки шагов, кнопки, ссылки.
- Отступы: шаг 4 px (4, 8, 12, 16, 24, 32, 40, 48, 64).
- Скругления: 24 px — карточки, плашки, окна; 16 px — варианты ответа и блоки QR; 12 px — картинки и QR внутри; капсула — кнопки и плашки-даты.
- Кликабельные элементы: курсор-рука, состояние при наведении (кнопки приподнимаются и светлеют, ссылки становятся белыми, крестик поворачивается), рамка фокуса для клавиатуры.

## Структура

```
index.html               страница целиком, блоки подписаны комментариями
assets/
  css/
    base.css             шрифт заголовков, сброс, типографика, кнопки, синяя карточка
    hero.css             первый экран и плашка перехода на платформу под ним
    sections.css         «Как участвовать», вводка, блоки активностей, финальный блок
    modal.css            общий каркас окон поверх страницы
    quiz.css             окно демо квиза «Спроси дорогу»
    comic.css            окно с главой I комикса
    elka.css             окно «Как сделать игрушку»
  js/
    modal.js             открытие и закрытие окон (кнопки, крестик, Esc, возврат фокуса)
    quiz-data.js         три вопроса демо квиза
    quiz.js              логика демо квиза
    main.js              подключение окон комикса и «Елки», плавающий QR
  img/                   картинки (см. ниже)
  fonts/                 Ruslan Display и его лицензия, ПСБ Лавр
```

Стили и скрипты подключаются в `index.html` именно в этом порядке: сначала `base.css`, затем блоки, затем окна; `modal.js` раньше `quiz-data.js` и `quiz.js`.

Адаптив описан рядом с каждым блоком в его же файле. Ширины: десктоп от 1001 px, планшет до 1000 px, телефон до 640–700 px.

## Блоки страницы

1. Первый экран: логотип ПСБ, название, вводка, даты, Михаил с часами.
2. Плашка перехода на платформу (текст, QR, кнопка, ссылка) и «Как участвовать» (три шага и примечание про код).
3. «С чего все началось»: вводка к активностям.
4. «Спроси дорогу»: кнопка «Попробуй три вопроса» открывает демо квиза.
5. «Лес»: анимация раннера и кнопка перехода на платформу.
6. «Елка»: кнопка «Подробнее» открывает окно с тремя шагами.
7. «Живая сказка»: кнопка «Читать главу I» открывает окно с комиксом.
8. «Пряничная избушка».
9. «Сундук чудес».
10. Финальный блок с QR и кнопкой.

## Окна поверх страницы

У каждого окна в разметке одинаковый набор id с общим префиксом: `qm` (квиз), `em` («Елка»), `cm` (комикс).

| id | что это |
|---|---|
| `префикс` | само окно, видно при классе `on` |
| `префиксOpen` | кнопка на странице, которая открывает окно |
| `префиксScroll` | прокручиваемая область окна |
| `префиксClose` | крестик |
| `префиксClose2` | ссылка «Закрыть» внизу окна |

Новое окно подключается одной строкой: `PSB.modal.setup('префикс')`.

## Шрифты

Заголовки набраны шрифтом Ruslan Display (лицензия SIL Open Font License 1.1, файл `assets/fonts/OFL-RuslanDisplay.txt`). Основной текст, кнопки и подписи набраны фирменным шрифтом банка ПСБ Лавр (файлы `assets/fonts/PSBLavr-*.woff2` и `.woff`: Regular, Italic, Medium, Bold).

Кириллический файл шрифта встроен прямо в `assets/css/base.css` строкой base64, чтобы заголовки при загрузке страницы сразу рисовались нужным шрифтом, без подмены. Файлы в `assets/fonts` остаются запасными. Чтобы заменить шрифт, перекодируйте новый `.woff2` в base64 и вставьте строку в `base.css` вместо текущей.
